# Security policy

This project is a public beta. Security fixes and supported versions may change while the deployment and collection paths are being validated. Use the latest release; older snapshots may contain unresolved issues.

Please report vulnerabilities privately through this repository's **GitHub Security Advisories** reporting feature. Include the affected commit or version, a clear reproduction, impact, and any suggested fix. Do not post exploit details or credentials in public issues. If private reporting is not enabled in the repository settings, open a public issue requesting a private contact channel without disclosing the vulnerability details.

Do not use live accounts, production data, or other people's systems to test a report. Maintainers will acknowledge and triage reports when available; no response-time or bounty commitment is offered during the beta.

If you discover an exposed credential, revoke or rotate it promptly before relying on removal from a repository or build artifact. See [DEPLOY.md](DEPLOY.md) for server-only credential handling and public deployment requirements.
